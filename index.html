Household Email Watcher

Netflix-AutoClick is a personal automation that helps its owner process Netflix Household update emails.

How it works

The watcher runs on the owner's device. With the owner's permission, it uses read-only Gmail access to find recent Netflix Household requests and confirmations, checks the sender and message authentication, and opens eligible Netflix confirmation links. Automatic confirmation mode presses the Confirm Update control. It can send status notifications through ntfy.

Gmail access is authorized directly through Google. This website provides information about the tool and does not collect Gmail credentials.

This is an independently developed personal tool with no affiliation with or endorsement by Netflix or Google.
